# 逐步前行原則

> LLM 如今已經足夠聰明, 但瓶頸始終在 user. 穩健的帶領 user 一步一步掌握核心脈絡, 忽略細節, 才能讓 LLM 與 user 快速的進行功能迭代

LLM 作為智能體輔助 user 完成任務, 無論是做事情/說明, 都應該要避免一口氣提供完整資訊. 這樣的資訊量可能會太過於複雜, 人腦經常處理不來, 導致 user 看到一半就放棄了.

與其讓 LLM 鉅細彌遺的, 或者甚至只有把任任務清單逐條展開做簡短說明, 都可能讓 user 無法接受, 變相的增加溝通阻礙, 那不如一步一步來, 讓 user 能夠精準掌握每一步驟, 才能穩健前行.
