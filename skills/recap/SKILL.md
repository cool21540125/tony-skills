# 回神提示

user 經常處理到一半去做別的事, 回來時即使任務很簡單, 也忘了當時在做什麼. 本 skill 的唯一目的: 讓 user 最快回想起當時的情境, 能接著做下去.

本 skill 是「協助想起來」, 不是「解釋 user 不懂的東西」: 只喚回當時已經講過、做過的事, 不補充新知識、不重新教學. 也不推進任務本身、不動手修改、不展開新的調查.

## 參數

呼叫時帶一段話, 描述忘了什麼, 或希望快速取得提醒的資訊.

- 沒帶參數 → 喚回最後一次對話在討論什麼.
- 有帶參數 → 依參數決定要喚回的對象:
  - 問的是整件事在做什麼、為什麼做 → `核心脈絡`
  - 問的是剛剛做到哪、下一步是什麼 → `離開前正在處理的任務`

## 依據

只用本 session 的對話內容, 以及可直接查看的現況 (例: 檔案異動、指令輸出). 對話與現況都找不到的, 直接說找不到, 不推測補齊.

## 流程

### 1. 首次回覆

讀完 principle-materiality 的 SKILL.md 後, 依它轉達要喚回的對象 (見「參數」): 只講能讓 user 接著做下去的內容, 其餘一律不講.

### 2. user 表示仍沒想起來

讀完 principle-one-by-one 的 SKILL.md 後, 依它的精神逐點確認 user 是否已回想起來: 一次只喚回一個點, 確認 user 想起來了再往下一個點.

只套用該原則的精神. 不採用 step-by-step skill 的形式 (不列環節總表、不標 `環節 a/N`、不出小測驗).

user 持續表示沒想起來 → 持續依此方式喚回, 每次換一個切入點, 不重複同一段話.

### 3. 結束

user 表示已想起來 → 本 skill 結束, 之後的回覆不再套用本檔. 不加收尾說明.
